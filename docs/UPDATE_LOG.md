# Update Log

프로젝트의 주요 업데이트를 날짜별로 기록합니다.

## 2026-09-04

### 분석 기능 확장
- 날짜형 컬럼을 연·월·일·요일 파생변수로 변환해 학습에 사용합니다. 이전에는 감지 후 제외만 했습니다. 변환은 전처리 파이프라인 안에서 이루어지므로, 저장된 모델에 원본 형태의 DataFrame을 그대로 넣어도 동일하게 동작합니다.
- 하이퍼파라미터 격자 탐색을 선택 기능으로 추가했습니다. CLI는 `--tune`, 웹은 고급 옵션의 체크박스입니다. 기본값은 꺼짐이며, 탐색은 학습 분할 안에서만 수행해 검증 데이터가 새지 않습니다. 데이터가 적어 탐색이 무의미할 때는 건너뛰고 경고를 남깁니다.

### 리포트
- 생성한 차트 25개 중 상관 히트맵 1개만 리포트에 실리던 문제를 고쳤습니다. 히스토그램은 수치형 변수 요약 절에, 박스플롯은 이상치 요약 절에 함께 실립니다.
- 차트 경로를 퍼센트 인코딩합니다. 컬럼명에 공백이 있으면(`fixed acidity`) Markdown 링크가 깨지던 문제를 막습니다.

### 개발 환경
- 개발 컨테이너 이미지를 Python 3.11에서 3.12로 올려 로컬·배포 환경과 버전을 맞췄습니다.

### 회귀 계수 해석 수정 (같은 날 추가)
- 회귀계수표가 더미 변수 함정에 걸려 있었습니다. 범주형 변수를 전체 원핫으로 펼친 뒤 상수항을 더하면 더미들의 합이 상수항과 같아져 설계행렬의 랭크가 부족해지고, 계수가 유일하게 결정되지 않습니다. OLS 해석 경로에만 기준 범주 방식을 적용해 계수를 식별 가능하게 만들고, 어떤 범주가 기준인지 화면에 안내합니다. 예측용 파이프라인은 상수항을 더하지 않으므로 전체 원핫을 그대로 씁니다.

### 웹 변수 선택 수정 (같은 날 추가)
- 웹 UI가 타깃을 뺀 모든 컬럼을 기본 선택하고 있어, 명시 지정 시 동작하지 않는 식별자 자동 제외가 무력화되고 있었습니다. `customer_id` 같은 컬럼이 모델에 그대로 들어가 회귀 대시보드의 Adj. R²와 F 통계량이 nan으로 표시됐습니다. CLI와 같은 규칙으로 기본 선택에서 빼고, 무엇을 왜 뺐는지 화면에 표시합니다.
- 의존성을 실행용(`requirements.txt`)과 개발용(`requirements-dev.txt`)으로 분리했습니다. 직접 import 하면서 선언하지 않았던 `numpy`와 `joblib`을 명시하고, 간접 의존이던 `openpyxl`·`tabulate`에는 필요한 이유를 주석으로 남겼습니다.
- 배포 후 `KeyError`가 났던 사례(설정 키 추가 시 Streamlit Cloud의 모듈 캐시 문제)를 `docs/DEPLOY.md` 트러블슈팅에 정리했습니다.

- 리포트의 차트 이미지 경로가 절대경로로 기록되던 문제를 고쳐 상대경로(`charts/...`)로 저장합니다. 결과 폴더를 옮기거나 공유해도 이미지가 깨지지 않고, 로컬 경로도 노출되지 않습니다.
- Markdown/JSON/HTML 산출물을 BOM 없는 UTF-8로 저장하도록 변경했습니다. 이전에는 BOM 때문에 `json.load()` 등 표준 방식으로 JSON 산출물을 읽으면 실패했습니다.

### 문서
- README를 처음 보는 사람이 프로젝트를 파악할 수 있도록 다시 썼습니다. 파이프라인 흐름도, 모듈별 역할, 설계 의도, 알려진 한계를 추가했습니다.
- 실제 실행 산출물을 `docs/sample_run/`에 포함해 설치 없이 결과 리포트를 볼 수 있게 했습니다.

### 개발 환경
